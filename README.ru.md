Просматривайте источники, цитируемые в Word, и вставляйте цитирования из Zotero нажатием клавиши или перетаскиванием.

## Возможности

| Функция                | Описание                                                                                               |
| ---------------------- | ------------------------------------------------------------------------------------------------------ |
| Подборки по документам | Временная подборка цитируемых записей личной библиотеки для каждого сеанса Word                        |
| Столбец Citation       | Текст цитирования: `[1]`, `[1, 2]` или «автор — год»                                                   |
| Горячая клавиша        | Вставка выбранных записей в Word по клавише апострофа `'` в Zotero                                     |
| Цитирование при чтении | Цитирование родительской записи открытого вложения                                                     |
| Перетаскивание         | Вставка одной или нескольких записей из списка Zotero в Word                                           |
| Штатная интеграция     | Стили, объединение соседних цитирований и обновления выполняет Zotero, без вставки статического текста |

## Установка

1. Скачайте `zotero-citation.xpi` со страницы [Releases](https://github.com/MuiseDestiny/zotero-citation/releases).
2. В менеджере плагинов Zotero выберите установку дополнения из файла в меню с шестерёнкой и укажите XPI.
3. Проверьте работу штатных команд **Add/Edit Citation** и **Refresh** в Word.
4. Вставьте цитирование Zotero или нажмите **Refresh** в документе с цитированиями.
5. Вернитесь в Zotero: появится временная подборка Word. В меню заголовков списка включите **Citation**.

Манифест заявляет поддержку **Zotero 7–11**. Требуется **настольный Microsoft Word в Windows или macOS**, а не веб-версия Word, WPS или LibreOffice. Конкретные сочетания версий требуют проверки.

> Плагин зависит от штатной интеграции Zotero и не заменяет надстройку Word. В macOS определение имени документа может потребовать разрешения Zotero на управление Word.

## Использование

### Подборки по документам

После создания сеанса Word плагин добавляет временную подборку со значком Word в личную библиотеку и обновляет её состав по данным цитирований.

-   Каждому сеансу соответствует отдельная подборка.
-   Имя документа определяется по метаданным; резервное имя — `Word (1)` и т. п.
-   Последующие проверки учитывают переименование и «Сохранить как». Имена подборок, изменённые вручную, сохраняются.
-   Записи не копируются. Добавляются только записи личной библиотеки, не групповых библиотек.

**Это временные представления, а не постоянные списки.** Очистка выполняется при удалении сеанса, отключении плагина или закрытии окна Zotero. При запуске также очищаются принадлежащие плагину подборки после аварийного завершения. Удаление подборки не удаляет записи библиотеки.

Для постоянного списка добавьте записи в собственную обычную подборку. Переименование временной подборки не делает её постоянной.

### Столбец Citation

Включите **Citation** в меню заголовков списка. Выбранная подборка плагина определяет документ; в остальных случаях используется текущий сеанс Zotero. Без подходящего сеанса или цитирования ячейка пуста.

Внутритекстовые стили показывают текст из сеанса; несколько упоминаний выводятся вместе. **Для стилей с примечаниями показывается порядок первого появления источника, а не фактический номер каждой сноски Word.** После удаления или перемещения цитирований в Word нажмите **Refresh**: столбец отражает последнее состояние, обработанное Zotero.

### Горячая клавиша `'`

1. Поставьте курсор в нужное место Word.
2. Выберите одну или несколько записей в Zotero.
3. Нажмите апостроф `'` для передачи записей штатному механизму цитирования.

Во вкладке чтения цитируется родительская запись вложения. Отдельный PDF без родителя не создаёт пустое цитирование. В полях поиска и других полях ввода апостроф не запускает команду.

### Перетаскивание

При видимом **Citation** перетащите обычные библиографические записи из любого столбца списка в нужное место Word.

-   **Показ Citation включает режим, скрытие отключает.** Горячая клавиша работает независимо.
-   Перетаскивание в подборки Zotero сохраняет штатное поведение и не вставляет цитирование в Word.
-   Вложения, заметки и смешанное выделение используют штатный механизм Zotero.
-   Отмена или отпускание за пределами Word не отправляет цитирование.

Рядом с `[1]` Zotero может объединить новый источник в `[1, 2]` вместо `[1][2]`. Результат зависит от позиции курсора, существующих цитирований и стиля.

## Принцип работы

Плагин связывает **сеансы цитирования Zotero, список записей и штатную интеграцию Word**. Он не распаковывает и не сканирует `.docx` для получения списка цитирований и не реализует запись полей Word самостоятельно.

### 1. Синхронизация подборок

[`src/modules/citation.ts`](src/modules/citation.ts) каждую секунду проверяет Word-сеансы в `Integration.sessions`, пропуская обновления во время обработки документа Zotero.

-   `citationsByItemID` содержит соответствия записей и цитирований; `citationsByIndex` — порядок первого появления.
-   Сравнение множеств ID позволяет добавлять и удалять участников подборки в транзакции базы данных.
-   Данные столбца кешируются; уведомления Zotero вызывают перерисовку.

Ключи собственных временных подборок сохраняются в локальной настройке для очистки. Распознаются и специальные маркеры старых версий. Подборки не удаляются только по имени; старые сохранённые поиски без подтверждённой принадлежности автоматически не удаляются.

### 2. Определение имени по метаданным

[`src/modules/wordDocuments.ts`](src/modules/wordDocuments.ts) примерно каждые пять секунд запрашивает имена открытых документов и свойства Zotero: через **PowerShell/COM в Windows** и **AppleScript в macOS**.

Свойства `ZOTERO_PREF_1`, `ZOTERO_PREF_2` и далее объединяются и разбираются классом Zotero `DocumentData`. Полученный `sessionID` связывает документ с сеансом — заголовок активного окна не используется. Неоднозначные совпадения с одинаковым ID исключаются. Сбой определения имени не мешает синхронизации существующих сеансов.

### 3. Штатная вставка цитирования

[`src/modules/cite.ts`](src/modules/cite.ts) находит родителей вложений, исключает неподходящие записи и дубликаты, затем вызывает `addEditCitation`.

Публичного API `insertCitation(items)` в Zotero сейчас нет. Плагин временно отслеживает окна цитирования, распознаёт окно своей команды, скрывает его, добавляет ID записей в `CitationEditInterface` и вызывает `accept()`. Необходимые диалоги, например первоначальная настройка стиля, остаются под управлением Zotero.

Загрузка полей, объединение, форматирование и запись выполняются Zotero. Плагин не заменяет `Session.cite()` или `execCommand()` и не содержит отдельного форматировщика. Временные наблюдатели затем удаляются.

### 4. Столбец и события перетаскивания

[`src/modules/views.ts`](src/modules/views.ts) регистрирует столбец через `ItemTreeManager` и перехватывает перетаскивание обычных записей на уровне DOM. Тип `zotero/item` сохраняется для внутренних подборок. Для внешнего отпускания учитываются отмена и сведения ОС об окне под указателем; см. [`src/modules/wordTarget.ts`](src/modules/wordTarget.ts).

Quick Copy и метод дерева `onDragStart` не заменяются. Значки Word добавляет обратимая обёртка метода. При отключении удаляются обработчики и столбец, восстанавливаются значки.

> Внутренние данные сеансов и интерфейсы окон не являются стабильными публичными API. Обновления Zotero или Word-интеграции могут потребовать адаптации. Подробности: [Citation integration](docs/citation-integration.md).

## Решение проблем

-   **Нет подборки?** Одного открытия Word недостаточно: вставьте цитирование или нажмите **Refresh** и дождитесь завершения.
-   **Нет имени документа?** Выполните команду Zotero в Word и подождите; проверьте разрешения автоматизации macOS. Причиной могут быть отсутствующие метаданные, одинаковые ID или диалог Word. Ручное имя не делает подборку постоянной.
-   **Подборка осталась после закрытия Word?** Zotero может сохранять сеанс. Подборки следуют сеансам, не окнам; отключение плагина или Zotero запускает очистку.
-   **Перетаскивание не работает?** Покажите Citation, выберите обычные записи и отпустите внутри Word. Проверьте **Add/Edit Citation**, завершите текущие операции и диалоги.
-   **Ошибка интеграции?** Проверьте соответствие надстройки Word вашей установке Zotero; при необходимости переустановите её из настроек цитирования Zotero. Плагин не обходит неисправную штатную интеграцию.

## Разработка и проверка

Используются TypeScript и esbuild:

```bash
npm ci
npm test
npm run tsc

# Локальная сборка без изменения манифеста обновлений
npm run build-prod -- --no-update
```

Результат: `build/zotero-citation.xpi`. Изолированный тест среды Zotero:

```bash
npm run test:runtime
```

По умолчанию запускается `/Applications/Zotero.app/Contents/MacOS/zotero`; путь меняется через `ZOTERO_BIN`. Используются временные каталоги профиля и данных. Проверяются настоящее дерево записей, события перетаскивания и диалоги; документная часть заменена тестовой: **реальная запись в Word не проверяется**. Межпрограммное перетаскивание мышью и Windows COM требуют проверки на соответствующих платформах.
